# 🤖 repopilot - AI That Codes, You Approve

## 🎯 What Is repopilot?

repopilot is a friendly helper that uses artificial intelligence to work on your software projects automatically. Think of it as a smart assistant that reads your goals, looks at feedback from your users, and makes improvements to your code—all while keeping you in control. You decide what gets changed and when to put those changes into action.

This tool is perfect if you manage a project on GitHub and want to save time on routine coding tasks. Instead of writing every line yourself, repopilot suggests tested, reviewable changes that you can accept or reject with a simple click.

## ✨ Key Features

| Feature | What It Does For You |
|---------|----------------------|
| 🧠 **Verification-Driven** | Checks its own work before showing you anything, so you see fewer mistakes |
| 🏠 **Self-Hosted** | Runs on your own computer, keeping your data private and secure |
| 🎯 **Goal-Focused** | Turns simple descriptions of what you want into actual code changes |
| 📝 **Issue & PR Reader** | Understands GitHub Issues and Pull Request comments to know what needs fixing |
| ✅ **Tested Changes** | Every suggestion comes with tests to prove it works |
| 🛑 **Bounded Execution** | Has limits on what it can do automatically—no runaway actions |
| 👤 **Human Control** | You always approve before anything gets merged or deployed |

## 🛠️ How to Use repopilot

Using repopilot is like giving instructions to a very capable assistant. Here's how it works in everyday terms:

### 📝 Creating a Task

1. Open repopilot.
2. Type what you want done in plain English. For example: *"Fix the login bug where users can't reset passwords."*
3. Click the **"Start"** button.

repopilot will then:
- Read your request carefully.
- Look at your project's code.
- Make the necessary changes.
- Show you a summary of what it did.

### 👀 Reviewing Changes

Before anything is applied to your project, repopilot shows you:
- **What files were changed** (click to see the differences).
- **The tests it ran** (to make sure nothing broke).
- **A simple explanation** of the changes in everyday language.

You can then choose:
- **✅ Approve** – Accept the changes and add them to your project.
- **❌ Reject** – Discard the changes and try something different.
- **✏️ Edit** – Modify the changes before approving.

### 🔄 Working with GitHub

If you connect your GitHub account, repopilot can:
- **Watch your Issues** – When someone reports a problem, repopilot can suggest a fix automatically.
- **Respond to Pull Requests** – If a reviewer asks for changes, repopilot can update the code accordingly.
- **Create branches** – It works in a safe, separate copy of your code until you approve.

### 🛡️ Staying in Control

You are always the boss. repopilot has built-in safety limits:
- It never merges code without your approval.
- It never deploys to production on its own.
- It stops if it detects something risky or confusing.

## 🆘 Troubleshooting Common Issues

Even with the best tools, sometimes things need a little help. Here are solutions to common problems:

### Problem: The download won't start.

- Check your internet connection.
- Try a different browser (like Edge or Chrome).
- Disable any pop-up blockers temporarily.
- Right-click the download link and choose "Save Link As."

### Problem: The installer says "Unknown Publisher."

This is normal for new software. To continue:
- Click "More Info" on the Windows warning screen.
- Then click "Run Anyway."
- Windows will remember this choice for future updates.

### Problem: repopilot won't open after installation.

- Restart your computer.
- Right-click the repopilot icon and select "Run as Administrator."
- Make sure your antivirus isn't blocking it. Add repopilot to your antivirus exceptions if needed.

### Problem: The AI seems slow or unresponsive.

- Check your internet speed.
- Close other programs that use a lot of memory.
- Wait a moment—some tasks take longer than others.
- Restart repopilot if it's been running for several hours.

### Problem: I accidentally approved a change I didn't want.

- repopilot keeps a history of all actions.
- Open the **"History"** tab.
- Find the change and click **"Undo"** to reverse it.
